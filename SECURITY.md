# Security policy

Please do not open a public issue for a suspected vulnerability or include
customer telemetry, credentials, secrets, or exploit payloads in this
repository.

Report security concerns privately to
[security@provenex.ai](mailto:security@provenex.ai). Include the affected
component or URL, impact, reproduction steps, and any relevant version or
commit. Send the smallest safe reproduction and redact all customer data and
credentials.

The materials in `samples/` are repository-owned synthetic fixtures and may be
discussed publicly. A result produced with customer data is not a public sample.
